# @zeekr-companion/shared-types

Types-only TypeScript package generated from the FastAPI OpenAPI schema. No runtime code, no React, no DOM.

- `src/api.d.ts`: generated by `openapi-typescript`. Do not edit.
- `src/index.ts`: stable names (`ServiceRecord`, `Vehicle`, `ApiErrorResponse`, `ApiErrorCode`, ...) re-exported from it.
- `tests/contract.test-d.ts`: compile-time checks against `docs/architecture/api-contracts.md` (error codes, error shape, `429` + `Retry-After`).

**Regenerate** after any API schema change: `cd packages/shared-types && npm install && npm run generate`, then commit `src/api.d.ts`. Needs `services/api/.venv` (or set `PYTHON`) with the API installed.

**Drift gate:** `npm run check:drift` regenerates into a temp directory and exits 1 on any difference. Also run `npm run typecheck`.
