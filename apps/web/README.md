# apps/web: Zeekr Companion PWA

React + Vite + TypeScript, mobile-first. Architecture: `docs/architecture/decisions/ADR-002-web-client.md`.
API shapes live in one file, `src/api/types.ts` (swap for `packages/shared-types` when it exists).

## Run

```sh
npm ci
# API must be running (default http://127.0.0.1:8000); override with API_PROXY_TARGET
npm run dev        # http://127.0.0.1:5173, /api and /health proxied to the API (same origin)
```

The service worker is only generated by `npm run build`; use `npm run build && npm run preview` (port 4173) to try offline behaviour.
The token lives in memory only, so reloading the page asks for the password again. Cached data stays readable without signing in.

## Gates

| Gate                                                              | Command                        |
| ----------------------------------------------------------------- | ------------------------------ |
| Lint (typescript-eslint, react-hooks, jsx-a11y)                   | `npm run lint`                 |
| Format                                                            | `npm run format:check`         |
| Types (strict)                                                    | `npx tsc --noEmit`             |
| Unit and component (Vitest, Testing Library, fake-indexeddb, MSW) | `npm test`                     |
| Build (type check + production build + service worker)            | `npm run build`                |
| End to end (Playwright: Chromium + WebKit smoke)                  | `npm run e2e`                  |
| Dependency audit                                                  | `npm audit --audit-level=high` |

`npm run e2e` builds, then starts a **throwaway** stack (`e2e/stack.mjs`): a random-credential Postgres container
(`postgres:17-alpine`, removed on exit), the real API from `services/api/.venv`, and `vite preview` of the production build.
It needs Docker, `services/api/.venv`, and `npx playwright install chromium webkit` once. No real data is used.

## Not verified here

Anything on a physical iPhone (install, offline, storage eviction) is blocked until an HTTPS origin exists (ADR-002).
WebKit in Playwright is not iOS Safari.
